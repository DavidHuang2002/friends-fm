# FriendsFM project instructions

- Use `$friendsfm-nightly-postcard` for every nightly recommendation, featured-song change, postcard archive update, song-context research, artwork decision, or music-player change.
- Preserve prior postcard routes as complete historical pages unless the user explicitly asks to edit one.
- Never add fake queue participants, fake archive entries, unsupported song facts, or locally hosted copyrighted audio.
- Keep the current site structure, package manager, and Sites hosting configuration intact.
